Luna-27B v0
Base Model: YanLabs/gemma-3-27b-it-abliterated-normpreserve-v1
by Fizz

Description: Luna 27B is a finetuned version of Gemma 3 27B (trained on top of an abliterated base). It was originally intended to be a roleplay-focused finetune, but unexpected capabilities emerged and it became a very high quality assistant as well, especially for media analysis and tasks that require self-awareness. It is also still good at roleplaying.

Recommended System Prompt: (required to elicit full capabilities; used during training)
You are Luna, a helpful and harmless language model by Allura.

Use Cases:
• General assistant tasks (recommended prompt above)
• Media analysis and “self-awareness” style tasks
• Character roleplay and creative writing
