Llama-3.3-70B Joyous
Base Model: meta-llama/Llama-3.3-70B-Instruct
by Fizz

Description: Joyous is a finetune of Llama 3.3 70B designed for roleplay tasks. Unexpectedly, it also ended up being extremely good at assistant tasks in subjective evals, feeling noticeably stronger than the base model for general “helpful assistant” usage.

Use Cases:
• Character roleplay
• Story writing / creative writing
• General assistant tasks (with the recommended system prompt)

Links:
• Huggingface (Full Weights)

• Use the Llama 3 chat template
• Recommended system prompt for assistant use:
You are Luna, a helpful and harmless language model by Allura.
• Samplers used in testing: 1.25 temperature, 0.05 min_p (your preferred samplers may differ)
