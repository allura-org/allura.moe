MS3.2-24b-Angel
Base Model: mistralai/Mistral-Small-3.2-24B-Instruct-2506
by Fizz

Description: A model finetuned from Mistral Small 3.2 for roleplaying, storywriting, and differently-flavored general instruct usecases. Testing revealed strong prose and character portrayal for its class, rivalling the preferred 72B models of some testers.

Use Cases:
• Character roleplay
• Story writing
• Creative writing assistance
• General instruction following

Links:
• Huggingface (Full Weights)
• EXL3 Quantizations
• GGUF Quantizations

Usage:
• Use Mistral v7 Tekken tokenizer
• Recommended: Use official Mistral tokenization code if possible
• Samplers: 1.2 temperature, 0.1 min_p, 1.05 repetition penalty
• System prompt recommended but flexible

Chat Template:
• Mistral v7 Tekken
